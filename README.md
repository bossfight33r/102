# Outlier Radar

Мониторит ниши на YouTube через официальный YouTube Data API v3, находит ролики-аутлайеры (набравшие намного больше обычного для своего канала), разбирает, почему они выстрелили, и каждое утро присылает в Telegram дайджест идей, адаптированных под ваш канал.
