# 0001. Корень репозитория = корень проекта

**Контекст.** ТЗ рисует каталог `outlier-radar/`, но репозиторий пустой и посвящён только радару.
**Решение.** Файлы проекта лежат прямо в корне репозитория (`src/radar`, `docs`, `config`…). Добавлены служебные модули вне схемы ТЗ: `app.py` (сборка зависимостей), `timeutil.py`, `bot/notifier.py`.
**Последствия.** Команды из корня: `make setup`, `uv run radar …`. Лишний уровень вложенности не нужен.
