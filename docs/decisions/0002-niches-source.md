# 0002. Ниши: YAML → БД

**Контекст.** SQLite — source of truth, но ниши удобно править в YAML; есть ещё `radar niche add`.
**Решение.** При каждом запуске ниши из `config/niches.yaml` upsert-ятся в таблицу `niches` (YAML побеждает для своих id). `radar niche add` пишет только в БД. Удаление ниши из YAML её не удаляет — выключайте `enabled: false`.
**Последствия.** Не нужно переписывать YAML из кода (комментарии не теряются).
