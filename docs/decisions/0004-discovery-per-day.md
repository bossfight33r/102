# 0004. discovery_per_day = число search.list в сутки на нишу

**Контекст.** В ТЗ «в пределах discovery_per_day» без единиц.
**Решение.** Это лимит вызовов `search.list` (100 ед.) на нишу за сутки квоты. Запросы ротируются по дню, чтобы за несколько дней пройти все `seed_queries`. Каналы кандидатов дорезолвливаются `channels.list` (1 ед. на 50 каналов) с purpose `discovery:<niche>`.
**Последствия.** Бюджет предсказуем: 2 запроса × 3 ниши = 600 ед./сутки.
