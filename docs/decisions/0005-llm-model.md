# 0005. LLM по умолчанию (заменено ADR 0015)

**Решение.** Модель берётся из `ANTHROPIC_MODEL`, по умолчанию `claude-opus-5-5`. Запросы через официальный SDK; по умолчанию включён серверный fallback при отказе модели (`fallbacks: "default"`, beta `server-side-fallback-2026-07-01`) и `effort: medium`; оба отключаются в `settings.yaml` (`llm.refusal_fallback`, `llm.effort`). Стоимость считается по ценам из `llm.*_usd_per_mtok` — при смене модели обновите цены.
**Последствия.** Модель меняется без правки кода; учёт стоимости зависит от актуальности цен в конфиге.
