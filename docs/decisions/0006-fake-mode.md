# 0006. Демо-режим RADAR_FAKE

**Решение.** `RADAR_FAKE=1` подставляет FakeYouTubeClient (на `tests/fixtures`), FakeLLM и FakeNotifier. `RADAR_NOW` фиксирует «текущее» время (фикстуры привязаны к 2026-10-06T06:00Z). `make demo` прогоняет tick без ключей и сети.
**Последствия.** Можно проверить весь конвейер на Маке до получения ключей.
