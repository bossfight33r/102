# 0008. Velocity без истории — вогнутый prior

**Контекст.** ТЗ: если истории снимков мало — сравнивать с views/day медианных видео. Прямое views/day зрелых видео (просмотры / 30 дней) завышает скорость любого свежего ролика в разы → ложные `fast_start`.
**Решение.** Fallback только для видео младше `baseline_min_age_days`: ожидание = `median_views · sqrt(age / 7)`. Для видео 7–14 дней без истории velocity не считается (ratio уже информативен). Интерполяция по снимкам допускается, только если есть снимок не позже `1.5·age + 6 ч` — один далёкий снимок не считается историей.
**Последствия.** На синтетике ложных срабатываний ≈ 0.3 %; заложенные аутлайеры находятся.
