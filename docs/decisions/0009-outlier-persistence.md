# 0009. Хранение аутлайеров

**Решение.** Таблица `outliers` — одна строка на видео (upsert). `detected_at` фиксируется при первом пересечении порога, остальные поля обновляются при каждом скоринге. Если видео опустилось ниже порога, запись не удаляется (история). Дайджест берёт свежие по `detected_at` и ещё не отправленные.
