# 0010. Кеш анализа

**Решение.** Анализ кешируется в `analyses` с `input_hash` = sha256(метаданные видео без статистики + профиль канала + модель + текст промпта). Просмотры, динамика и комментарии в хеш не входят: иначе каждый новый снимок вызывал бы повторный платный анализ. Проверка кеша — до запроса комментариев и превью (не тратим квоту). `--force` игнорирует кеш.
Невалидный ответ LLM: одна повторная попытка с текстом ошибки, затем LLMError; упавшее видео не повторяется 24 ч. Дневной лимит расходов — `analysis.max_cost_usd_per_day` по `llm_usage` за последние 24 ч.
