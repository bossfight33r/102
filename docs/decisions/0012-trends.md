# 0012. Тренды и рекомендации

**Решение.** Тренд = признак, который у аутлайеров встречается чаще, чем у всех видео ниши за окно: сглаженный lift = ((k_out+0.5)/(n_out+1)) / ((k_all+0.5)/(n_all+1)). «Растущий» — lift ≥ 1.2 и ≥ 2 аутлайеров с признаком; стрелка ↑/↓ — сравнение с предыдущим окном той же длины. Признаки: эвристики заголовков (число, вопрос, капс, первое лицо, «как»…), формат, корзины длительности, день и время публикации (по `digest.timezone`).
Рекомендации по порогам — правила по отметкам «Не то» (≥ 3) против остальных показанных в дайджесте; пишутся в `data/exports/threshold_recommendations.yaml`, конфиг не меняется. Еженедельный отчёт — по `trends.weekly_weekday/hour`, один раз за ISO-неделю.
