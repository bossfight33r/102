# 0013. Миграции схемы

**Решение.** `db._MIGRATIONS` — список (версия, SQL), применяется последовательно по `PRAGMA user_version` при открытии БД. Новые изменения схемы — только добавлением следующей версии (без правки старых). v2: `videos.gone_at` — видео, отсутствующее в ответе videos.list, исключается из снимков (append-only история не трогается).
