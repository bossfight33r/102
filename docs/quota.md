# Квота YouTube Data API

Дневная квота проекта Google Cloud по умолчанию — **10 000 единиц**, сброс в полночь по America/Los_Angeles. Сутки в `quota_ledger` считаются так же.

## Стоимость вызовов (config `quota.costs`)

| Метод | Единиц | Где используется |
|---|---|---|
| `videos.list` | 1 (до 50 id) | метаданные новых видео, снимки статистики |
| `channels.list` | 1 (до 50 id или 1 handle) | добавление каналов, подписчики, кандидаты |
| `playlistItems.list` | 1 (до 50 элементов) | новые видео каналов через uploads-плейлист |
| `commentThreads.list` | 1 | топ-20 комментариев для анализа |
| `search.list` | **100** | discovery по seed_queries |

Search не используется для watchlist: новые видео — только через uploads-плейлист.

## Бюджет (пример: 3 ниши, 60 каналов, ~1200 активных видео)

| Задача | Расчёт | Ед./сутки |
|---|---|---|
| Watchlist | 60 каналов × 24 опроса × 1 | 1 440 |
| Подписчики каналов | 60 / 50 → 2 вызова × 1 раз | 2 |
| Снимки <14 дней (каждые 6 ч) | ~300 видео / 50 × 4 | 24 |
| Снимки 14–60 дней (раз в сутки) | ~900 / 50 | 18 |
| Discovery | 3 ниши × 2 search × 100 + резолв каналов | ~606 |
| Комментарии для анализа | ~10 аутлайеров | 10 |
| **Итого** | | **~2 100** |

Самое дорогое — частота опроса watchlist: `watchlist.interval_minutes` = 60 → 24 вызова на канал в сутки. Для 200+ каналов поднимите интервал до 120–180 минут.

## Правила планировщика (`youtube/quota.py`, ADR 0003)
- `discovery_reserve` (по умолчанию 2 000) держится под discovery: остальные задачи его не тратят.
- Дорогие методы (`≥ expensive_threshold`, по умолчанию 50) и discovery не тратят последние `safety_margin` единиц.
- Если вызов не помещается — `QuotaDeferred`: задача откладывается до следующего tick (не падает).
- `quotaExceeded` от API — пауза до сброса квоты + алерт в бот (раз в сутки).
- Ретраи с экспоненциальной паузой — на 5xx, 429, rateLimitExceeded и сетевые ошибки. Каждая попытка, дошедшая до API, — один вызов в журнале на уровне обёртки (ретраи внутри HTTP-клиента не пишутся отдельно; Google может списать их — держите `safety_margin`).

Посмотреть расход: `radar quota`.
