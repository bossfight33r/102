# Скоринг

Код: `src/radar/score/baseline.py` (математика базлайна), `src/radar/score/outliers.py` (score, флаги, задача). Параметры — секция `scoring` в `config/settings.yaml`. Шортсы и длинные видео скорятся раздельно: у каждого формата свой базлайн.

## Базлайн канала
Выборка — последние `baseline_videos` (30) видео канала **того же формата**, старше `baseline_min_age_days` (7), по последнему снимку. При оценке видео, которое само попадает в выборку, оно исключается (leave-one-out).

- `median_views` = медиана просмотров выборки
- `mad` = MAD натуральных логарифмов просмотров: `median(|ln v_i − median(ln v)|)`
- `reliable` = `sample_size ≥ min_sample` (8)

## Метрики
- **ratio** = `views / median_views`
- **robust z** (лог-шкала) = `(ln views − ln median_views) / (1.4826 · max(mad, min_log_mad))`. 1.4826 переводит MAD в σ; `min_log_mad` (0.15) не даёт делить на ноль у «ровных» каналов.
- **velocity_ratio** (только видео младше `velocity_max_age_days` = 14):
  1. *history*: просмотры видео сейчас / медиана просмотров других видео канала **в том же возрасте** (линейная интерполяция по их снимкам; нужно ≥ `velocity_min_videos` = 3 видео с историей, покрывающей этот возраст);
  2. *prior* (истории мало, видео младше 7 дней): против медианного видео, приведённого к возрасту вогнутой кривой `median_views · sqrt(age / 7)` — это и есть «views/day медианных видео» с поправкой на то, что ролики набирают просмотры в первые дни быстрее. Ставит флаг `velocity_fallback`;
  3. иначе не считается.

## Итоговый score
```
score = w_r · log2(ratio) + w_z · z + w_v · log2(velocity_ratio)
если reliable = false и score > 0:  score · unreliable_factor
```
По умолчанию `w_r = 1.0`, `w_z = 0.5`, `w_v = 0.7`, `unreliable_factor = 0.6`.
**Аутлайер**: `views ≥ min_views` (1 000) **и** `score ≥ score_threshold` (3.0). Анализ LLM — только при `score ≥ analysis.score_threshold` (3.5).

## reason_flags
| Флаг | Условие |
|---|---|
| `high_ratio` | ratio ≥ `flag_ratio` (3) |
| `high_z` | z ≥ `flag_z` (2.5) |
| `fast_start` | velocity ≥ `flag_velocity` (2) |
| `early_signal` | fast_start у видео младше 7 дней |
| `views_exceed_subs` | просмотров больше, чем подписчиков |
| `small_channel_breakout` | подписчиков < `small_channel_subs` (10 000) и просмотров ≥ подписчиков |
| `low_confidence` | базлайн ненадёжен (малая выборка) |
| `velocity_fallback` | velocity посчитана по prior, а не по истории |

## Разобранные примеры
1. **Явный аутлайер.** Медиана 20 000, MAD_ln 0.2, выборка 30. Видео 10 дней, 260 000 просмотров. ratio = 13 → log2 = 3.70; z = ln 13 / (1.4826 · 0.2) = 2.565 / 0.2965 = **8.65**; velocity нет (старше 7 дней, без истории). score = 3.70 + 0.5 · 8.65 = **8.03** → аутлайер, флаги `high_ratio`, `high_z`.
2. **Мало данных.** Выборка 5 видео (reliable = false), медиана 20 000, MAD 0.3. Видео 60 000: ratio 3 → 1.585; z = 1.0986 / 0.4448 = 2.47 → 1.235; сумма 2.82 · 0.6 = **1.69** → не аутлайер, хотя ×3.
3. **Ранний сигнал.** Медиана 20 000, MAD 0.25; видео 2 дня, 60 000 просмотров; типичное видео канала в 48 ч — 12 000 (по снимкам). ratio 3 → 1.585; z = 1.0986 / 0.3707 = 2.96 → 1.48; velocity 5 → log2 = 2.32 · 0.7 = 1.625. score = **4.69** → аутлайер, флаги `high_ratio`, `high_z`, `fast_start`, `early_signal`. С 30 000 просмотров (ratio 1.5, velocity 2.5) score = 2.06 — не аутлайер.
4. **Обычный разброс.** ×2 к медиане при MAD 0.25: z = 1.87, score = 1 + 0.94 = **1.94** — не аутлайер.
5. **Шум маленького канала.** Медиана 200, видео 900 (×4.5): score высокий, но `views < min_views` (1 000) → отсекается.

## Проверка
`tests/test_scoring.py`: синтетические каналы с заложенными аутлайерами (длинный, шортс, ранний по скорости), шумный канал без аутлайеров, маленький канал; на фикстурах YouTube находятся ровно `tgLONGOUT01`, `tgSHORTOUT1`, `sbBREAKOUT1`. На 40 сидах шумных каналов (σ_ln = 0.3) доля ложных срабатываний ≈ 0.3 %.
